# Отчёт реализации v0.5.4

## Сделано

1. Реальная карта лояльности проверяется через I-Retail.
2. По отчёту `iretail_exhibition_probe_20260618_063113_readonly.zip` рабочий личный код `0736816` проходит через поле `code`.
3. Баланс клиента теперь отображается из `result.amount[]`.
4. Для тестовой карты корректно ожидается `0 PTS`; скидка при этом не применяется.
5. Локальный запасной вход в лояльность отключён, чтобы не показывать ложный успех.
6. Заказ хранит будущую сумму `ibonus_discount_sum` как `ibonusDiscountSum`.
7. В альбомном режиме добавлен экран найденной карты.

## Проверки

В контейнере нет Android SDK, поэтому APK здесь не собирался. Выполнена структурная проверка файлов и связей v0.5.4, отчёт лежит в `test_reports/validation_v0.5.4.json`.
