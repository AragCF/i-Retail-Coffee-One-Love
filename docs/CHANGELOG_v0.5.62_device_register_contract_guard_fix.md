# CHANGELOG v0.5.62 — исправление device/register contract guard

Дата: 21.09.2026.

## Ошибка v0.5.61

Проверка `verify_v0_5_61_device_register_contract.py` искала `versionCode` регулярным выражением с двойным экранированием и получила `None`.

## Исправлено

- корректное выражение `versionCode\s+(\d+)`;
- отсутствие совпадения теперь даёт обычный FAIL вместо исключения;
- версия повышена до 0.5.62.

Контракт 1.0.0 не изменён. Рабочего вызова `device/register` нет.
