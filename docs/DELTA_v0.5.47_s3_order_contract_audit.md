# DELTA v0.5.47 — аудит актуального контракта заказа S3

Дата: 21.09.2026

## Основание

S2 закрыт живой проверкой:
`REFRESH success=true source=I-Retail ZIP products=8 offers=8 categories=2`.

S3 DRY_RUN уже формирует локальный черновик заказа, но реальная отправка в `iretail/order/synchronize` остаётся заблокированной отсутствием подтверждённого wire-контракта.

## Цель

Получить с актуального apiDoc I-Retail фактическое описание маршрутов заказа и зафиксировать:
- reserve-order-id / id;
- synchronize;
- employee_id;
- pin;
- channel_id;
- currency_id;
- products / offer_id / quantity / price;
- формат тела;
- схему ответа;
- возможные правила повторов, идемпотентности и восстановления статуса.

## 🟢 Добавляется

- Windows/curl-сценарий только для чтения актуальной документации;
- автоматический поиск order/iretail/order страниц из `api/apidoc/actual/index.html`;
- сохранение найденных HTML-страниц;
- текстовый индекс совпадений по ключевым словам;
- автоматическая упаковка и публикация ZIP в Git.

## 🔴 Не добавляется

- вызов `iretail/order/synchronize`;
- создание или изменение заказа на сервере;
- оплата;
- фискализация;
- изменение текущего S3 DRY_RUN.

## ⚠️ Правило

До разбора актуальной документации реальная отправка заказа остаётся запрещённой.
