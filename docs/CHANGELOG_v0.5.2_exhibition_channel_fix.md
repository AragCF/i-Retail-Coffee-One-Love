# i-Retail Android UI v0.5.2 — канал «Выставка», карточки и лояльность

## Что изменено

1. Проверочный канал переключён с `3115` на `3476`.
2. Проверочный профиль переключён с `ООО "Демо Магазин"` на профиль «Выставка» (`profile_id=2512`, найден ранее в списке профилей).
3. В конфиг добавлены данные текущей проверки устройства: `device_code=6287`, `device_id=6287`.
4. Исправлено наложение текста в карточках альбомного режима: название, объём и цена теперь разводятся по разным вертикальным зонам.
5. Лояльность больше не проверяется через прямые вызовы Merchant API i-Bonus. Приложение использует только I-Retail API.
6. Для кода лояльности `0736816` добавлены проверочные варианты полей через `iretail/client/get-coupons-and-balance`; окончательно рабочее поле нужно подтвердить отдельным отчётом probe v1.2.
7. Сообщение о некофейном канале больше не содержит жёстко пришитый `3115`; оно показывает фактический канал из конфига.

## Что ещё требует проверки

1. Подтвердить, что `3476` — именно `channel_id`, а не внутренний номер компании/точки.
2. Подтвердить живой ZIP-каталог по `channel_id=3476`: количество категорий, товаров и кофейных позиций.
3. Подтвердить сценарий лояльности по персональному коду `0736816`.
4. Только после подтверждения структуры заказа подключать `iretail/order/synchronize` и поле `ibonus_discount_sum`.
