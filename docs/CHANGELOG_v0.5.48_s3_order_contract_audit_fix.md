# CHANGELOG v0.5.48 — исправление Windows-аудита контракта заказа S3

Дата: 21.09.2026

## Причина выпуска

Первый живой запуск `S3_02_FETCH_ORDER_API_DOCS.bat` завершился до загрузки документации.

Фактическая ошибка PowerShell:

`Invoke-WebRequest : A positional parameter cannot be found...`

## Причина

В Windows PowerShell имя `curl` занято встроенным псевдонимом `Invoke-WebRequest`.

В v0.5.47 вспомогательная функция называлась `Curl`. PowerShell разрешил это имя как встроенный alias, поэтому вместо нашей функции был вызван `Invoke-WebRequest`.

## 🟢 Исправлено

- вспомогательная функция переименована в `Invoke-CurlToFile`;
- обращения к ней обновлены;
- сам исполняемый файл вызывается только как `curl.exe`;
- добавлен автоматический запрет функции с именем `Curl`;
- добавлена проверка наличия `Invoke-CurlToFile`;
- добавлена проверка явного вызова `curl.exe`;
- версия поднята до `0.5.48-s3-order-contract-audit-fix`.

## 🔴 Не меняется

- аудит по-прежнему выполняет только GET документации;
- реальные маршруты заказа не вызываются;
- `iretail/order/synchronize` не включён;
- S3 DRY_RUN остаётся без сетевой отправки.

## Следующий шаг

Повторить `S3_02_FETCH_ORDER_API_DOCS.bat`.
