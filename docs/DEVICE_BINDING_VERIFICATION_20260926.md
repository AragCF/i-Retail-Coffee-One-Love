## Обязательное действие перед настоящей активацией

Прежний PIN следует перевыпустить в личном кабинете. В предварительной диагностике мой фильтр пропустил активационный PIN из поля code в журнал GitHub Actions. Созданный запуск 36253752452 удалён вместе с журналом и вложением; это не доказывает отсутствия чтения до удаления и не отзывает код. Код не отправлялся в запрос регистрации. Новый PIN вводится только на JL22; повторно присылать его в чат не требуется.

## Дальнейшая приёмка

Обновить ветку без принудительного сброса, запустить MAIN_41_DEVICE_BINDING_SAFE_TEST.bat, ввести реквизиты из раздела 2.2 личного реестра, ID устройства 3669 и новый PIN. Канал и профиль руками не задавать. При сохранённой привязке и неполной загрузке повторять только загрузку настроек. При неизвестном результате активации не повторять PIN и не удалять данные; нужна сверка с ЛК.
