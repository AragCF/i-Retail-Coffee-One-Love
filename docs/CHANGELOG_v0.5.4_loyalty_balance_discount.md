# i-Retail Android UI v0.5.4 — реальная лояльность через I-Retail

## Изменения

- Подтверждённый канал `5676` оставлен как рабочий источник меню.
- Лояльность переведена на подтверждённый метод `iretail/client/get-coupons-and-balance`.
- Для личного кода клиента первым проверяется поле `code`.
- Ответ I-Retail разбирается по `result.amount[]`, `result.externalId`, `result.coupons[]`.
- Убрана опасная локальная подмена успешного входа в лояльность при ошибке сервера.
- Бонусы больше не подставляются «из воздуха»: если баланс 0, скидка 0.
- В заказ добавлены поля `grossAmount`, `ibonusDiscountSum`, `loyaltyExternalId`, `loyaltyBalanceLabel`.
- Оплата показывает сумму уже с учётом применённой скидки.
- Для альбомной ориентации добавлен отдельный экран найденной карты лояльности.

## Ограничение

Синхронизация заказа в I-Retail ещё не включена. В рабочей Java-системе найдено поле `ibonus_discount_sum` и метод `iretail/order/synchronize`, но для безопасного включения в Android нужен отдельный тестовый запуск на тестовом заказе.
