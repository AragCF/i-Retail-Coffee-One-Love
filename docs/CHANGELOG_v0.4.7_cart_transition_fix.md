# iRetail Android UI v0.4.7 — правки корзины и переходов

## Что исправлено

1. В строках корзины убрана лишняя подпись «В заказе:». Теперь название товара начинается сразу с имени позиции.
2. В альбомной ориентации переразложена строка корзины: название, объём, кнопки «− / Изм. / +» и цена больше не накладываются друг на друга.
3. Подпись «ЧТО ВЫБЕРЕТЕ СЕГОДНЯ?» в альбомной ориентации выровнена по центру экрана.
4. При переходах между экраном товара, каталогом и корзиной живые слои очищаются сразу, а альбомный экран не успевает показать растянутый портретный макет. Это убирает короткое «злое» наложение старого и нового экранов.
5. Добавлено мягкое появление живого слоя после перерисовки, чтобы действия с товаром выглядели спокойнее.

## Проверка перед выдачей

Проведена статическая проверка основного Kotlin-файла: баланс фигурных скобок и круглых скобок сходится. Полная сборка APK в контейнере не выполнялась, потому что здесь нет установленного Android Gradle Plugin/SDK в рабочем окружении.
