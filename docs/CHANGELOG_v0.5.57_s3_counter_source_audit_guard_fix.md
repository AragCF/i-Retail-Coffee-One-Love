# CHANGELOG v0.5.57 — исправление защитных проверок S3

Дата: 21.09.2026.

## Причина

Автоматическая сборка v0.5.56 остановилась на историческом guard `verify_v0_5_55_s3_dry_run_v2.py`, который ошибочно требовал точные:

- `versionCode 55`;
- `versionName 0.5.55-s3-dry-run-v2`;
- версию Windows-сборщика 0.5.55.

После нормального повышения версии этот тест неизбежно становился ложным отрицанием.

## Исправлено

- guard DRY_RUN v2 теперь требует версию **не ниже** 0.5.55;
- counter-source guard требует версию **не ниже** 0.5.56;
- сценарии запуска и публикации переведены на 0.5.57;
- версия приложения и сборщика повышена до 0.5.57;
- логика самого документационного аудита не менялась.

## Безопасность

Никаких новых рабочих API-вызовов не добавлено. Аудит остаётся GET-only по `api/apidoc/actual`.
