# DELTA v0.5.38 — объединённая приёмка S2 + S3

Дата: 20.09.2026  
Основа: `v0.5.37-s3-order-draft`.

## Назначение

Не добавлять новую бизнес-логику, а объединить живую проверку S2 и безопасного черновика S3 в один цикл на одном APK.

## 🟢 Добавлено

- один сценарий `S23_01_BUILD_INSTALL_ACCEPTANCE_AUDIT.bat`;
- единый ZIP-отчёт с:
  - журналом обновления каталога;
  - снимком экрана;
  - `order_sync_draft.json`;
  - сведениями об установленной версии;
  - явной отметкой, что платёж выбирать нельзя;
- проверка выпуска `tools/verify_v0_5_38_acceptance.py`.

## 🟡 Изменено

- версия APK: `0.5.38-s2-s3-acceptance`, `versionCode 38`;
- основной workflow использует версионно-независимую проверку S3;
- локальные build/cache/log каталоги исключаются из Git;
- README синхронизируется с текущей веткой.

## 🔴 Не добавлено

- нет сетевой отправки `iretail/order/synchronize`;
- нет реального платежа;
- нет фискализации;
- нет изменений wire-протоколов;
- нет Multicard.

## ⚠️ Безопасность

При живой проверке пользователь добавляет товары и открывает экран способов оплаты, но **не выбирает карту, наличные или онлайн-оплату**. Сценарий предназначен только для доказательства каталога, денежных сумм и локального JSON-черновика.
