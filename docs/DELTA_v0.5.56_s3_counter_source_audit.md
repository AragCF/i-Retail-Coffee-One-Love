# DELTA v0.5.56 — S3: поиск безопасного источника счётчиков

Дата: 21.09.2026.

## Причина выпуска

Живой DRY_RUN v2 версии 0.5.55 успешно прошёл на JL22 и подтвердил безопасную границу: текущие `device_id`, `shift` и `counters` нельзя подставлять догадками.

Документация уже указывает `device/register(device_code)` как источник этих значений, но это регистрационный метод. Перед разрешением такого вызова нужно исчерпать read-only путь.

- `S3_13_PUBLISH_COUNTER_SOURCE_AUDIT.bat`;

- автоматический поиск **всех** страниц контроллеров `iretail/*` из текущего `apidoc/actual/index.html`;
- поиск каждого упоминания:
  - `order_counter`;

  - `check_counter`;
  - `counters`;
- сохранение контекста и ближайшего документированного маршрута.

## Граница безопасности

Сценарий выполняет исключительно GET опубликованной HTML-документации.

Он не выполняет:
- авторизацию;
- `device/register`;
- чтение или изменение рабочей смены;
- `employee/authorize`;
- `payment-in/create`;
- `order/synchronize`.

Классификация маршрутов по названию является лишь подсказкой для анализа, а не доказательством read-only семантики.
