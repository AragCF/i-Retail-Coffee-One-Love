# CHANGELOG Windows CLI build v0.4.1

## Причина выпуска

Windows-сборка падала на задаче `:app:clean`, потому что Gradle не мог удалить папку:

```text
app\build\outputs\apk\debug
```

Причина из лога: Windows сообщила, что папка используется другим процессом.

## Что изменено

- `BUILD_WINDOWS_CLI.bat` больше не выполняет `clean` по умолчанию.
- Основной режим теперь сразу делает `:app:assembleDebug`.
- Добавлен режим `--clean`.
- Добавлен режим `--hardclean`.
- Ошибка `clean` больше не останавливает сборку, а выводится как предупреждение.
- Перед сборкой скрипт останавливает старые Gradle daemon-процессы через `gradle --stop`.
- APK копируется в `dist` с временной меткой, чтобы не зависеть от заблокированного `latest`-файла.
- Инструкция `docs/BUILD_WINDOWS_CLI.md` обновлена под новую схему.

## Что не менялось

- Kotlin-код приложения не менялся.
- XML-каталог не менялся.
- Экранная логика не менялась.
- Gradle-конфигурация приложения не менялась.
