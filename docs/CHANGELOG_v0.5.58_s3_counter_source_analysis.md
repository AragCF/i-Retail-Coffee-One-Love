# CHANGELOG v0.5.58 — автоматический разбор S3 counter-source отчёта

Дата: 21.09.2026.

## Причина

Живой аудит v0.5.57 проверил 28/28 страниц документации и нашёл 18 совпадений counter-полей, включая 3 read-only-кандидата. Сам отчёт опубликован в Git как ZIP.

## Добавлено

- `tools/analyze_s3_counter_source_report.py`;
- автоматический разбор последнего ZIP в GitHub Actions;
- вывод read-only-кандидатов и соответствующего документального контекста;
- группировка counter-полей по ближайшим маршрутам.

## Локальная чистота репозитория

В `.gitignore` добавлены сырые каталоги:

- `test_reports/s3_dry_run_v2/S3_DRY_RUN_V2_*/`;
- `test_reports/s3_counter_sources/S3_COUNTER_SOURCES_*/`.

ZIP-отчёты не игнорируются.

## Безопасность

Новых сетевых вызовов нет. Версия 0.5.58 анализирует только уже опубликованный диагностический архив.
