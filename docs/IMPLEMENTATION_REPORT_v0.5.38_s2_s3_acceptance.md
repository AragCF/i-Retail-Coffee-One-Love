Получить один воспроизводимый и безопасный живой прогон для двух незакрытых доказательств:

1. S2 — реальный каталог I-Retail и точные денежные суммы;
2. S3 — локальный черновик будущего серверного заказа без сетевой отправки.

## Что должен доказать живой прогон

### S2
В `02_catalog_logcat.txt` должен быть результат:

`REFRESH success=true source=I-Retail ZIP ...`

Именно `I-Retail ZIP`, не `I-Retail ZIP cache`.

### S3
В свежем `04_order_sync_draft.json` должны быть:
- `mode = DRY_RUN_ONLY`;
- `send_allowed = false`;
- `validation.lines_equal_gross = true`;
- фактические `offer_id`, количество и точные цены выбранных товаров.

Старый черновик перед прогоном удаляется, поэтому он не может подменить свежий результат.

## Финансовая безопасность

Приёмочный сценарий запускает приложение с `real_pos_enabled=false`. Пользователь также не выбирает никакой способ оплаты. Карточный Kozen в этом прогоне не нужен.
