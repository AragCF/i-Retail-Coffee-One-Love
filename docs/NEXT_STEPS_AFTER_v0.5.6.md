# Следующие шаги после v0.5.6

## 1. Проверить внешний вид кнопки удаления

Собрать APK, открыть заказ, добавить товар, посмотреть красную кнопку очистки заказа.
Ожидаемый результат: белая иконка корзины по центру красной кнопки, без белого квадрата и без кривого PNG.

## 2. Проверить основной путь заказа

1. Добавить товар.
2. Открыть заказ.
3. Проверить карту лояльности `0736816`.
4. Вернуться в заказ.
5. Убедиться, что карта видна в заказе, а скидка равна `0 ₽`.
6. Нажать «Оплатить».
7. Пройти демонстрационный путь оплаты.

## 3. Следующая большая интеграция

Следующий серьёзный этап — не дизайн, а создание заказа через I-Retail:

- изучить `iretail/order/synchronize` из рабочей системы TSO;
- подготовить безопасный пробник, который сначала формирует JSON заказа и сохраняет его в отчёт;
- после подтверждения структуры включить отправку заказа отдельным явным флагом;
- только после успешного пробника переносить синхронизацию заказа в Android-приложение.

Это лучше делать аккуратно, потому что синхронизация заказа уже создаёт реальные записи в I-Retail.
