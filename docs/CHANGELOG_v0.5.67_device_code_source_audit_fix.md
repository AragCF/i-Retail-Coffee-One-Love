# CHANGELOG v0.5.67 — исправление PowerShell-аудита device_code

Дата: 21.09.2026.

## Ошибка v0.5.66

В PowerShell-файле для вызова curl использовался cmd.exe-разделитель строк `^`. Статический PowerShell parser остановил выпуск до живого запуска.

## Исправлено

- авторизация формируется через массив `$authArgs`;
- синтаксис остаётся совместимым с Windows PowerShell 5.1;
- набор разрешённых API-вызовов не изменён;
- device/register отсутствует.

Версия повышена до 0.5.67.
