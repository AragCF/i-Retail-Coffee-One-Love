# Vendotek VT: доступ к веб-меню подтверждён, нужен пароль

Дата: 18.09.2026. Дополнение к этапу 0.5.33. Программа и настройки терминала не изменяются.

## Новое подтверждение на устройстве

После описанной процедуры пользователь открыл на телефоне **VENDOTEK web config** по адресу **192.168.4.1**. На снимке видны поле `Enter password here` и кнопка `Login`.

Доступ до формы авторизации подтверждён. Точная версия проекта и прошивки пока не прочитана. Этот результат не подтверждает интернет самого терминала, TMS или готовность платежей.

Пользователь также сообщил, что через некоторое время сеть пропадает и приходится повторять вход с перезапуском. Длительность сеанса и состояние светодиодов при исчезновении сети пока неизвестны.

## Пароль

Актуальный пароль этого экземпляра не установлен. В переданном экспорте проектной переписки и ранее полученных иллюстрациях VT значения пароля нет. Поиск открытых источников не дал подтверждённого стандартного пароля для VT.

Официальная инструкция Vendotek для VN/VL направляет за паролем меню техника в техническую поддержку. Это подтверждённый порядок для описанных моделей, а не доказательство одинакового пароля у всех терминалов. Для нашего VT нужно запросить действующий пароль именно **VENDOTEK web config** у поставщика, подготовившего тестовый экземпляр, или у поддержки Vendotek.

## Исчезновение сервисной сети

Тайм-аут режима настройки — гипотеза, не установленная причина. Точный лимит для этой прошивки не найден. Возможны завершение сервисного режима, перезапуск терминала либо потеря подключения только на телефоне; текущих данных недостаточно для выбора.

На схеме изготовителя для VTKPOS-V2 синий и красный светодиоды горят при нахождении в Wi-Fi-меню. Во время следующего входа полезно отметить время до исчезновения сети, остаётся ли её имя видимым на втором устройстве и повторяется ли начальная последовательность загрузки. Последнее позволит отличить перезапуск от одного лишь закрытия меню, но не установит причину перезапуска.

## Следующее действие

Получить пароль, повторить уже сработавший вход, авторизоваться, прочитать **Terminal Info**, настроить **Settings → Link Settings → Wi-Fi**, сохранить и выполнить **Reboot**. После обычной загрузки использовать ранее выданные `VENDOTEK_12_STATUS_AFTER_WIFI.bat` и `GIT_123_PUBLISH_VENDOTEK_NETWORK_RESULT.bat`. Эти сценарии не получают пароль и не выполняют финансовую операцию.
