# CHANGELOG v0.5.63 — type guard для контракта device/register

Дата: 21.09.2026.

## Новое доказательство

Опубликованная документация `device/register` описывает возвращаемый `type_slug` как:
- `workplace_cashier`;
- `self_service_terminal`.

Ранее найденное устройство 3476 имеет тип `coffee_machine`.

## Изменено

Контракт повышен до 1.0.1 и теперь явно запрещает:
- отождествлять возвращённое register-устройство с coffee_machine 3476;
- автоматически записывать возвращённый device_id/type_slug в рабочую конфигурацию;
- продолжать интеграцию без анализа фактического типа и состояния.

Рабочего вызова `device/register` в этом выпуске нет.
