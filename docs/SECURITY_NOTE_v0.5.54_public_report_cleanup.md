# SECURITY NOTE v0.5.54 — очистка публичного диагностического отчёта

Дата: 21.09.2026

Во время анализа живого отчёта v0.5.53 обнаружено, что вложенное поле с именем, оканчивающимся на `token`, не было отредактировано старой точной проверкой ключа.

Приняты меры:
1. публичная ветка `v0.5.53-s3-safety-scan-fix` принудительно возвращена к коммиту до публикации ZIP;
2. новый v0.5.54 редактирует любые ключи, оканчивающиеся на:
   - `token`;
   - `password`;
   - `secret`;
3. дополнительно редактируются лишние account/user/offline-shop identifiers;
4. ZIP-валидатор независимо блокирует любые неотредактированные token/password/secret поля;
5. фактическое секретное значение в документации не воспроизводится.

Ограничение: удаление ссылки на коммит из публичной ветки не гарантирует мгновенное физическое удаление объекта из инфраструктуры Git-хостинга. Если соответствующий token можно перевыпустить в i-Retail, это следует сделать.
