# Отчёт реализации v0.5.66 — S3 device_code source audit

## Цель

Проверить, откуда должен браться настоящий device_code для регистрации кассового устройства, не выполняя вторую регистрацию.

## Что читается

1. Список устройств канала.
2. Device info для найденных устройств.

## Что сохраняется

Только безопасные признаки:
- device_id;
- тип устройства, если он есть;
- наличие server code;
- длина server code;
- совпадение server code с config device_code;
- совпадение server code с device_id;
- наличие external_code;
- длина external_code;
- совпадение external_code с config device_code.

Сами code/external_code, device_code, токены и учётные данные в отчёт не записываются.

После живого ZIP будет понятно, существует ли на сервере отдельный код для device 3476 и отличается ли он от текущей конфигурации. Повтор device/register до анализа запрещён.
