# Отчёт реализации v0.5.2

## Контекст

В версии v0.5.1 канал `3115` технически загружал каталог I-Retail, но по смыслу это был не кофейный каталог: сервер отдавал парфюм, часы, сумки и другие некофейные товары. Поэтому приложение временно показывало безопасный кофейный набор из макета.

После уточнения от коллег для кофейной проверки указаны:

- компания: «Выставка»;
- предполагаемый канал/идентификатор: `3476`;
- код активации устройства: `6287`;
- тестовый код клиента лояльности: `0736816`.

## Сделано в исходниках

- Обновлён `app/src/main/assets/content/iretail-api.json`.
- Обновлена версия приложения: `0.5.2-exhibition-channel-fix`.
- Исправлена компоновка текстов в карточке товара, особенно в альбомной ориентации NoxPlayer.
- Убран прямой путь к Merchant API i-Bonus из логики приложения.
- Лояльность направлена через `iretail/client/get-coupons-and-balance`.
- Добавлены проверочные поля короткого кода клиента для будущего подтверждения по отчёту.

## Риск

`3476` пока не подтверждён как настоящий `channel_id` живым отчётом. Если это не канал, приложение упадёт обратно в безопасное поведение: покажет локальный кофейный набор или сохранённый кэш.
