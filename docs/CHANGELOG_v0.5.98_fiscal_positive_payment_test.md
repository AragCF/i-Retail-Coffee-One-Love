# CHANGELOG v0.5.98 — controlled fiscal positive payment test

Дата: 23.09.2026.

Добавлен защищённый испытательный режим для единственной разрешённой реальной карточной операции на 1,00 ₽.

Ключевые свойства:
- тестовый товар существует только при специальном Intent;
- обычный каталог не меняется;
- сумма жёстко проверяется как 100 копеек;
- количество строго 1, модификаторы/купоны/лояльность запрещены;
- перед PAYMENT создаётся одноразовый Android-маркер;
- предыдущая неопределённая оплата блокирует новую;
- real POS=true не сохраняется;
- после любого результата runtime real POS выключается;
- Windows-сценарий вторично сохраняет real POS=false;
- отчёт санитизируется до публикации;
- cloud-fiscal, order/synchronize и приготовление не вызываются.
