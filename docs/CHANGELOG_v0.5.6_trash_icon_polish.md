# v0.5.6 — полировка кнопки удаления

## Что изменено

1. Красная кнопка очистки заказа больше не использует PNG-иконку `ic_trash_source.png`.
2. Иконка корзины теперь рисуется программно через `Canvas`, поэтому не зависит от плотности экрана, прозрачности PNG и особенностей Android 6/NoxPlayer.
3. Размер иконки уменьшен и выровнен по центру кнопки, чтобы она выглядела аккуратно и не превращалась в белый квадрат.
4. Сохранены подтверждённые настройки живого каталога I-Retail:
   - профиль «Выставка»;
   - `profile_id=2512`;
   - `channel_id=5676`;
   - `currency_id=643`;
   - код устройства `6287`.
5. Сохранена текущая логика карты лояльности через I-Retail.

## Что не менялось

- Боевой каталог по-прежнему загружается из I-Retail ZIP.
- Карта `0736816` по-прежнему определяется через I-Retail.
- При нулевом балансе карта привязывается к заказу, но скидка остаётся `0 ₽`.
- Оплата и выдача кофе пока остаются демонстрационными локальными адаптерами.

## Проверка

Выполнена структурная проверка исходников:

- баланс фигурных скобок в Kotlin/Gradle-файлах;
- наличие программной иконки корзины;
- отсутствие зависимости кнопки удаления от PNG `ic_trash_source`;
- сохранение рабочего канала `5676`;
- сохранение состояния лояльности.

Отчёт: `test_reports/validation_v0.5.6.json`.
