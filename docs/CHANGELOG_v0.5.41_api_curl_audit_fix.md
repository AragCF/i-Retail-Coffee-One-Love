# CHANGELOG v0.5.41 — исправление Windows/curl-аудита Retail API

Дата: 20.09.2026  
Основа: `v0.5.40-api-curl-audit`.

## Причина выпуска

Первый живой запуск `RAPI_01_FETCH_DOCS_AND_TEST_CATALOG.bat` остановился в PowerShell до авторизации и запроса каталога.

Фактическая ошибка:

`if : The term 'if' is not recognized...`

Причина — недопустимое для данного контекста выражение `size=(if (...){...}else{...})`.

## 🟢 Исправлено

- вычисление размера загруженного файла документации вынесено в обычный блок `if`;
- добавлен статический предохранитель против повторного появления конструкции `size=(if(...)`;
- версия поднята до `0.5.41-api-curl-audit-fix`;
- Windows-сценарии привязаны к новой ветке;
- CI и имя артефакта обновлены до 0.5.41.

## ⚠️ Важно

Ошибка 0.5.40 возникла до этапов:
- авторизации I-Retail;
- получения access token;
- запроса каталога.

Поэтому прежний неудачный прогон не даёт сведений о работоспособности API и должен быть повторён на 0.5.41.

## Приёмка

Успехом считается:
1. сценарий проходит загрузку документации;
2. выполняется авторизация;
3. выполняется запрос каталога;
4. формируется безопасный ZIP-отчёт;
5. ZIP автоматически публикуется в Git.
