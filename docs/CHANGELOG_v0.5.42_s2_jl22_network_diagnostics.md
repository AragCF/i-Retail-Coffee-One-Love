# CHANGELOG v0.5.42 — JL22 network diagnostics for S2

Дата: 20.09.2026

## Основание

Windows/curl-аудит v0.5.41 доказал:
- Retail API доступен;
- авторизация успешна;
- access token выдаётся;
- каталог возвращается HTTP 200 как application/zip;
- каталог содержит categories.json и offers_0000.json;
- в offers_0000.json 8 доступных предложений;
- структура совместима с текущим Android-разборщиком.

Следовательно, следующий диагностический шаг — локализовать отказ именно на JL22 / Android 6.

## 🟢 Добавлено / усилено

- S2_02_CATALOG_DIAGNOSTICS.bat теперь рассчитан на текущую ветку v0.5.42;
- тот же сценарий после формирования ZIP сам вызывает публикацию в Git;
- строгий автоматический выбор JL22 по сигнатуре ADB сохраняется;
- при неоднозначности остаётся нумерованное меню выбора устройства;
- Retail API Windows-аудит можно повторно запускать и в этой ветке;
- проверка Retail API вынесена в версионно-независимый guard.
