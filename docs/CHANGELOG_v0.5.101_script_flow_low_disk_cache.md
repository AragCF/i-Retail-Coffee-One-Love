# CHANGELOG v0.5.101 — script continuation and low-disk cache policy

Дата: 23.09.2026.

## Причина выпуска

Живой запуск v0.5.99 успешно собрал основной APK и Kozen Bridge, но завершился сразу после шага [2/10].

Причина — особенность cmd.exe при `DisableDelayedExpansion`: переменная `KOZEN_APK` назначалась внутри скобочного блока и там же проверялась через `%KOZEN_APK%`. При разборе блока cmd подставлял старое пустое значение и выполнял тихий `exit /b 24`.

Финансовая попытка при этом не начиналась.

## Исправление шага [2/10]

- `KOZEN_APK` теперь задаётся до условного блока;
- после успешной сборки bridge явно проверяется существование APK;
- сценарий обязан перейти к [3/10] установке основного APK;
- `DelayedExpansion` по-прежнему отключён, поскольку путь проекта содержит символ `!`.

## Правило свободного места

По требованию пользователя:

- при свободном месте **2 ГБ и более** ничего не очищается, Gradle работает как раньше с обычным build cache;
- при свободном месте **менее 2 ГБ** включается режим очистки восстановимых кэшей и для текущей сборки отключается Gradle build cache;
- после очистки требуется минимум 1 ГБ, иначе сборка безопасно прекращается.

При нехватке места очищаются:
- локальный `.gradle` и каталоги `build` текущего репозитория;
- временные Gradle build-cache / transforms / jars;
- Gradle daemon и .tmp;
- Kotlin daemon caches;
- Android user cache;
- временные каталоги Gradle/Kotlin/Android в `%TEMP%`;
- если после этого по-прежнему меньше 2 ГБ — Gradle dependency cache `modules-2`.

Не удаляются:
- исходники;
- Git;
- Android SDK packages;
- пользовательские документы и прочие рабочие каталоги.

Финансовый контракт S3_FISCAL_POSITIVE_PAYMENT_CONTRACT_v1.0.1 не изменён.
