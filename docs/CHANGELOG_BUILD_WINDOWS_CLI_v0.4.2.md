# CHANGELOG Windows CLI v0.4.2

## Исправлено

- Исправлена ошибка сборки `compileDebugKotlin`, возникавшая при распаковке нового архива поверх старой рабочей папки.
- Добавлена автоматическая очистка устаревшего файла `app/src/main/java/com/coffeeonelove/iretail/ui/MockGateways.kt`.
- Добавлена страховка в `app/build.gradle`: Gradle удаляет известные устаревшие исходники перед `compile`, `assemble` и `bundle`.
- Добавлена совместимость модели `Product` со старым именованным вызовом без `offerId`, чтобы случайно оставшиеся v0.3-файлы не ломали сборку до очистки.

## Почему это произошло

ZIP-распаковка поверх существующей папки обновляет и добавляет файлы, но не удаляет файлы, которых больше нет в архиве. Поэтому старый `MockGateways.kt` из v0.3 мог остаться рядом с новой `IntegrationGateways.kt` и попасть в компиляцию Kotlin.

## Что делать пользователю

Обычный сценарий: запустить `BUILD_WINDOWS_CLI.bat`.

Если рабочая папка сильно загрязнена старой сборкой: запустить `BUILD_WINDOWS_CLI.bat --hardclean`.

Самый чистый сценарий: распаковывать архив в новую пустую папку.
