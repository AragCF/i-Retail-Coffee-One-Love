# S3 — повторная контролируемая положительная проверка после устранения rc=99

Версия контракта: 1.0.2  
Дата: 24.09.2026  
Статус: **PROPOSED_NOT_APPROVED**

## Основание

Контракт v1.0.1 разрешал ровно одну реальную карточную операцию 1,00 ₽.

Эта попытка была использована и завершилась определённым SmartSkyPOS-отказом:
- `approved=false`;
- `rc=99`;
- `amount=1.00`.

Повторная операция по v1.0.1 запрещена.

## Условие активации v1.0.2

Этот контракт может быть переведён в `APPROVED_FOR_ONE_ATTEMPT` только после двух независимых условий:

1. ВПП / поставщик эквайринга подтверждает, что причина `rc=99` устранена либо терминал переведён на корректный рабочий профиль.
2. Пользователь отдельно и явно разрешает ещё одну реальную карточную операцию.

До выполнения обоих условий PAYMENT запрещён.

## Предлагаемый повторный тест

Если контракт будет одобрен:

- ровно один товар;
- цена: 1,00 ₽ / 100 копеек;
- количество: 1;
- только банковская карта;
- без купона;
- без лояльности;
- без бонусов;
- без сиропа;
- без собственного стакана.

## Цель

Доказать цепочку:

`ручной выбор 1 ₽ → ручное нажатие «Банковская карта» → APPROVED → RuntimeOrder=PAID → FiscalGateway → DRAFT_READY`

## Не меняется

- Windows не отправляет PAYMENT;
- автоматический retry запрещён;
- повтор после любого финального результата запрещён;
- persisted real POS остаётся false;
- cloud fiscal не вызывается;
- order/synchronize не вызывается;
- приготовление не запускается;
- все отчёты санитизируются.

## Текущий статус

**НЕ ОДОБРЕН. Финансовых действий по этому контракту выполнять нельзя.**
