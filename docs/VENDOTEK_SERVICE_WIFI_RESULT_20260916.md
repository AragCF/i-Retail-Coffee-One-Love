# Vendotek VT — результат пассивного поиска сервисной Wi‑Fi сети

Дата результата: 16.09.2026  
Архив: `VENDOTEK_SERVICE_WIFI_20260916_142407.zip`  
Исходная ветка: `v0.5.26-vendotek-service-wifi`

## Результат

Пассивное сравнение эфира при выключенном и включённом Vendotek завершилось штатно.

```text
OUTCOME=NO_NEW_SSID_SEEN

Vendotek OFF:
  CF_Festival

Vendotek ON, 24 последовательных сканирования:
  CF_Festival

New SSID candidates:
  NONE
```

Windows использовал адаптер Intel Wi‑Fi 6 AX200 и был подключён к `CF_Festival`. Никакого нового SSID, коррелирующего с включением Vendotek, за окно наблюдения не появилось.

## Что это означает

Результат не доказывает отсутствие Wi‑Fi меню в прошивке терминала. VTK-MAN-RU 1.0 прямо указывает поддержку входа в меню по Wi‑Fi для VTKPOS‑V2 на VT, однако точная аппаратная последовательность активации точки доступа для нашего безэкранного экземпляра в доступном текстовом описании не установлена.

Поэтому следующий безопасный шаг не предполагает нажатия неизвестных кнопок на плате и не пытается угадывать пароль или SSID.

## Следующий диагностический шаг

VTK-MAN-RU 1.0 раздел 3.2.2 описывает `POS Management data = A` как `Send keepalive` — запрос синхронизации терминала с TMS. Для нашего терминала уже подтверждены:

- VTK over FTDI `/dev/ttyUSB0`;
- IDL/CRC/TLV;
- STATUS;
- устойчивое состояние `STATE=BUSY,NOT_READY;READY,DESCRIPTION=IN_SERVICE` после холодной загрузки.

В ветке `v0.5.27-vendotek-tms-probe` подготовлен отдельный диагностический клиент, который после явного разрешения оператора отправляет ровно один `A`, наблюдает ответы `IDL`, `INF`, `CON`, `DAT`, `DSC`, Stage ID `921/922`, затем повторно читает STATUS.

### Важная граница безопасности

`A` не является финансовой командой: клиент не содержит `VRP`, `FIN`, `ABR`, `DIS`, команды сверки, обновления ПО, перезагрузки или выгрузки журналов.

Но это не строго read-only операция: если для терминала уже подготовлена конфигурация на TMS и терминал сможет связаться с сервером, синхронизация может получить/применить уже размещённые сервером параметры. Поэтому запуск разрешается только после явного подтверждения человеком в Windows-сценарии.
