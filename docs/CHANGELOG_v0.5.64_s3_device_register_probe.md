# CHANGELOG v0.5.64 — контролируемый одноразовый device/register probe

Дата: 21.09.2026.

## Разрешение

Контракт 1.0.1 получил статус `APPROVED_FOR_SINGLE_PROBE`.

## Реализовано

- read-only снимок устройства/смены «до»;
- две устойчивые метки одноразовой попытки;
- ровно один `iretail/device/register(device_code)`;
- отключённые curl retries и redirects для register;
- безопасное сохранение ответа без секретов;
- read-only снимок «после»;
- сравнение device IDs до/после;
- фиксация возвращённых counters/shift/type_slug;
- запрет автоматической привязки нового устройства;
- ZIP-проверка и автоматическая публикация;
- отдельный read-only recovery сценарий без register.

## По-прежнему запрещено

- order synchronize;
- создание платежа;
- открытие/закрытие смены;
- employee authorize;
- register-external-system;
- update-info;
- любые команды кофемашине.

После живого отчёта никакой следующий изменяющий шаг автоматически не выполняется.
