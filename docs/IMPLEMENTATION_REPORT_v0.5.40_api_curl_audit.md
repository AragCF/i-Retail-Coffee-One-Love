# Отчёт реализации v0.5.40 — Windows/curl-аудит Retail API

## Реализовано

1. Отдельная ветка `v0.5.40-api-curl-audit`.
2. Сценарий одного запуска `RAPI_01_FETCH_DOCS_AND_TEST_CATALOG.bat`.
3. Получение актуального снимка apiDoc до API-проверки.
4. Авторизация через curl с тем же форм-urlencoded контрактом, что в Android.
5. Загрузка каталога через curl тем же набором полей, что в Android.
6. Сырое тело авторизации и access token остаются только во временном каталоге Windows.
7. Сохраняются безопасные HTTP-метаданные и каталог.
8. Добавлен отдельный контроль утечки секретов перед Git.
9. `RAPI_02_PUBLISH_LATEST_API_AUDIT.bat` автоматически коммитит и отправляет последний ZIP.
10. Добавлены статические проверки контракта и синтаксическая проверка PowerShell в CI.

## Ожидаемый пользовательский цикл

Один запуск `RAPI_01_FETCH_DOCS_AND_TEST_CATALOG.bat`:

- получает документацию;
- делает авторизацию;
- делает запрос каталога;
- формирует ZIP;
- проверяет ZIP на секреты;
- автоматически публикует ZIP в текущую ветку Git.

Дальше отчёт разбирается без ручной пересылки.
