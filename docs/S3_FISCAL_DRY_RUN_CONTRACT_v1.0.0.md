# S3 Fiscal DRY_RUN v1 — контракт

Версия: 1.0.0  
Дата: 22.09.2026  
Статус: IMPLEMENTED_SAFE_NO_NETWORK

## Основание

Переданный документ «API web-фискальник» описывает отдельный внешний API фискализации:
- create order;
- getStatus;
- callback;
- api_key + login;
- purchase/products;
- card_amount;
- invoice_url.

Документ датирован 2019 годом, поэтому его endpoint нельзя автоматически считать текущим боевым контрактом.

## Разрешено в v0.5.81

После **достоверно подтверждённой** карточной оплаты:
- построить локальный DRY_RUN;
- проверить точность денежных сумм;
- сформировать candidate form fields;
- сохранить локальный JSON во внутреннее хранилище приложения;
- записать безопасную диагностическую строку.

## Запрещено

- любые HTTP-запросы к cloud-fiscal;
- хранение api_key/login;
- утверждать, что чек сформирован;
- отправлять order/synchronize;
- менять device/counters/shift;
- автоматически выбирать FFD payment/type/vat без подтверждения;
- при order-level discount отправлять неподтверждённое распределение скидки по строкам.

## Блокеры боевой отправки

1. Подтвердить текущего fiscal provider.
2. Подтвердить актуальный endpoint.
3. Получить отдельные credentials безопасным способом.
4. Подтвердить FFD payment/type/vat.
5. Утвердить распределение iBonus discount по строкам.
6. Решить, является Fiscal API дополнением или заменой Retail order sync.
