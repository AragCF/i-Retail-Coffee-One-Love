# CHANGELOG v0.5.100 — Windows disk-space preflight

Дата: 23.09.2026.

Причина выпуска:
- живой запуск v0.5.99 остановился до финансовой попытки на Gradle `:app:processDebugResources`;
- причина: `There is not enough space on the disk`;
- падение произошло при упаковке локального Gradle build cache;
- PAYMENT не отправлялся, одноразовый финансовый маркер не создавался.

Изменено:
- Windows-сборка выполняется с `--no-build-cache`;
- перед сборкой измеряется свободное место на диске проекта;
- при свободном месте менее 2048 МБ автоматически очищаются только временные каталоги сборки текущего репозитория:
  - `.gradle`;
  - корневой `build`;
  - `build` внутри модулей;
- глобальные Gradle-кеши пользователя и другие проекты не затрагиваются;
- после очистки требуется минимум 1024 МБ свободного места;
- если места всё ещё недостаточно, сценарий останавливается до установки APK и до финансового режима;
- сборка Kozen bridge в контролируемом платёжном сценарии также запускается с `--no-build-cache`.

Финансовый контракт S3_FISCAL_POSITIVE_PAYMENT_CONTRACT_v1.0.1 не менялся.
