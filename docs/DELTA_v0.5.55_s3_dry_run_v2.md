# DELTA v0.5.55 — S3 DRY_RUN v2

Дата: 21.09.2026.

## Основание

Живые read-only проверки S3 доказали актуальную форму `order/synchronize`, справочники, налоговые данные, единственное серверное устройство канала и платёжные службы. Одновременно выяснено:

- configured `device_id=6287` не является доказанной кассой;
- устройство `3476` существует, но было offline и последний раз связывалось 29.05.2026;
- смена `164570` формально открыта, но устарела;
- актуальные `order_counter / operation_counter / refund_counter` не получены;
- `device/register(device_code)` документирован как источник device/counters/shift, но является отдельным контрактным решением.

## Что изменено

- локальный S3-черновик перестроен под документированную оболочку:
  - `device_id`;
  - `counters`;
  - `shift`;
  - `orders`;
  - `operations`;
- недоказанные текущие device/shift/counters и поля жизненного цикла остаются `null`;
- добавлена версия схемы `S3_DRY_RUN_V2`;
- добавлено состояние `BLOCKED_PENDING_DEVICE_REGISTER_DECISION`;
- каталог сохраняет дополнительные поля, уже присутствующие в живом ZIP: `id_yml`, `type_id`, `unit_id`, raw currency, `base_price`, `tax_id`;
- доказанный налог 29259 преобразуется в `tax_rate=0`, `tax_included_in_price=false`, `tax_number_in_printer=4` только когда товар действительно содержит этот tax_id;
- отдельный не-секретный snapshot доказательств хранит значения read-only аудита;
- добавлен живой сценарий `S3_10_BUILD_INSTALL_DRY_RUN_V2_AUDIT.bat` с автоматической безопасной публикацией результата.

## Что намеренно не сделано

Не добавлены вызовы:

- `iretail/device/register`;
- `iretail/order/synchronize`;
- открытия/закрытия смены;
- `employee/authorize`;
- `payment-in/create`.

Никакое старое устройство, старая смена, сотрудник-кандидат или платёжная служба не подставляются в wire-поля автоматически.

## Следующая граница контракта

После живой проверки DRY_RUN v2 остаётся одно принципиальное решение: разрешён ли штатный `device/register(device_code)` как способ получить актуальные device/counters/shift именно для этой кофемашины.
