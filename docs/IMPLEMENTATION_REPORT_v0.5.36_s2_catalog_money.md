# Отчёт реализации i-Retail v0.5.36 — S2

## Цель

Исправить потерю копеек при чтении каталога и исключить замену исправного локального каталога непроверенной сетевой выгрузкой.

## Реализовано

1. Цена товара и итоговые суммы получили точные поля в минимальных денежных единицах.
2. Сетевой и XML-каталоги разбирают цену через `BigDecimal` с двумя десятичными знаками.
3. UI считает корзину в `Long` и отображает копейки.
4. Kozen получает сумму, сформированную из того же точного значения.
5. Новый ZIP сначала разбирается в памяти, затем записывается во временный файл и повторно проверяется.
6. Старый кэш сохраняется как резервный на время замены.
7. Добавлен безопасный журнал результата обновления каталога.
8. Добавлен Windows-сценарий живой проверки каталога через ADB.

## Проверки
