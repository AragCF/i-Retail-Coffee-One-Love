# S3 — чек-лист ответа поддержки I-Retail

Дата: 22.09.2026.

Ответ поддержки считается достаточным для продолжения S3, если из него можно однозначно получить:

- [ ] правильный `type_slug`: `self_service_terminal` или `workplace_cashier`;
- [ ] решение по `device_id 6287`: существует / не существует / можно реактивировать;
- [ ] способ создания device, если его нет;
- [ ] способ получения `device_code` или `external_code`;
- [ ] какой register-метод использовать;
- [ ] источник `order_counter`;
- [ ] источник `operation_counter`;
- [ ] источник `refund_counter`;
- [ ] источник `shift_id`;
- [ ] источник `check_counter`;
- [ ] нужно ли открывать смену;
- [ ] правильный `service_in_slug` для внешнего POS.

До получения этих ответов:
- `order/synchronize` остаётся выключен;
- новые register-пробы запрещены;
- admin/device/create не вызывается;
- рабочий device_id приложения не меняется.
