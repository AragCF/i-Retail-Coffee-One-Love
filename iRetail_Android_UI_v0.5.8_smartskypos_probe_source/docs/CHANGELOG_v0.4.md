# CHANGELOG v0.4

## Добавлено

- Чтение каталога из `content/main-screen.xml`.
- Чтение способов оплаты из `content/pay-methods.xml`.
- Локальная модель заказа с номером, суммой, статусами и позициями.
- Безопасные адаптеры заказа, оплаты, лояльности и выдачи.
- Динамические подписи товаров в каталоге.
- Видимое управление первой позицией из мини-корзины главного экрана.
- Видимая кнопка назад на экране заказа.
- Видимые экранные клавиатуры купона и лояльности.
- Отчёты `IMPLEMENTATION_REPORT_v0.4.md` и `TSO_REFERENCE_NOTES_v0.4.md`.

## Исправлено

- Выбор напитка больше не сводится к капучино.
- Удаление позиции из мини-корзины больше не ведёт на старый неактуальный заказ.
- Редактирование позиции применяется к выбранной строке.
- Сироп можно добавить, увидеть и удалить.
- `У меня свой стакан` переключается по расширенной зоне касания.
- Купон можно закрыть без системных кнопок Android.
- Из лояльности можно вернуться назад без системных кнопок Android.
- Рекомендации после оплаты выбираются по разным карточкам и закрываются.

## Изменено

- `versionCode`: 5.
- `versionName`: `0.4.0-content-integration`.
- Имя выходного APK из Windows-скрипта: `dist/iRetail_Android_UI_v0.4-debug.apk`.

## Осталось на следующий контракт

- Реальная интеграция с i-Retail API.
- Реальная POS/MDB-оплата.
- Реальная фискализация и отправка чека.
- Реальная команда приготовления Jetinno JL22.
- Подключение Raspberry/Windows TSO-хаба как внешнего сервиса.
- Финальная вёрстка всех экранов не поверх PNG, а полноценными нативными компонентами.
