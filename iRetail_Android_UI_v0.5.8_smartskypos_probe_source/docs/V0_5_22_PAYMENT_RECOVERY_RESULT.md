# v0.5.22 — восстановление последней оплаты из основного i-Retail UI

Безопасное чтение истории SmartSkyPOS завершилось успешно (`RECOVERY_OK`). Финансовых команд при восстановлении не выполнялось.

## Последняя транзакция

`getLastTransaction()` вернул:

```text
approved=false
approvedPresent=true
message=Отказано
rc=99
rrn=625701637720
authCode=-
amount=57.00
currency=643
terminalId=12000679
receipt=8
type=00
```

Адресный `getTransaction(terminalId=12000679, receiptNumber=8)` независимо вернул те же значения.

Таким образом, операция на 57,00 RUB, инициированная из основного i-Retail UI, дошла до SmartSkyPOS и была сохранена как определённо завершённая отклонённая банковская операция. Для неё нет неопределённости транспорта и нет основания повторять тот же платёж автоматически.

`code=0` в диагностике получен штатным `Bundle.getInt("code")` при отсутствии ключа (`codePresent=false`) и не означает финансового одобрения. Решающий признак — `approved=false`; банковский/процессинговый код — `rc=99`.

## Что это доказывает и чего не доказывает

Результат исключает потерю ответа USB/AOA как причину конечного статуса транзакции receipt=8: SmartSkyPOS сохранил её с RRN и `approved=false`.

Но `rc=99` является общим отказом и сам по себе не позволяет определить, где именно сформирован отказ: в параметрах запроса, терминальной конфигурации, SmartSkyPOS или эквайринговом контуре.

Для изоляции нужен один A/B-тест: локальный вызов типизированного `SmartSkyPosGateway` непосредственно на Kozen P12, без JL22, USB/AOA и production bridge. Если такой локальный платёж одобряется, искать различие нужно в production bridge. Если локальный платёж также возвращает `rc=99`, причина находится ниже USB/AOA — в Kozen/SmartSkyPOS/терминальной или эквайринговой конфигурации.

Для этого добавлен `SMARTSKYPOS_07_LOCAL_ISOLATION_PAYMENT.bat`. Скрипт сам финансовую команду не отправляет: реальный платёж 1,00 RUB запускается только вручную на экране Kozen после READY и явного подтверждения оператора. Результат публикуется `GIT_111_PUBLISH_SMARTSKYPOS_LOCAL_RESULT.bat`.
