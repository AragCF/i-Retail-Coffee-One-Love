# v0.5.7 — исправление сборки

Исправлена ошибка компиляции `MainActivity.kt:827`: поле `Paint.strokeWidth` требует `Float`, а в v0.5.6 туда попадал `Int` из `px(4)`.

Изменение:

- `strokeWidth = px(4).toFloat()`

Функционально логика приложения не менялась: реальный каталог I-Retail, лояльность и полировка кнопки удаления сохранены.
