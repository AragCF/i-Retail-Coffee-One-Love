# i-Retail Android UI v0.5.3 — настоящий channel_id, прокрутка и статус источника

## Что исправлено

1. По отчёту `iretail_exhibition_probe_20260618_060036_readonly.zip` подтверждено: профиль «Выставка» имеет `profile_id=2512`, но переданный ранее `3476` не является рабочим `channel_id` для терминальных методов I-Retail.
2. Метод `channel/get-channels` для профиля «Выставка» вернул канал `id=5676`, `name=Выставка`, `use_ibonus_loyalty=true`.
3. Приложение переключено на `channel_id=5676`.
4. Лишняя полоса прокрутки в альбомной сетке убрана: если карточки помещаются по высоте, сетка рисуется без `ScrollView`.
5. Если каталог I-Retail не загружается и приложение показывает локальный макет, теперь выводится явная строка источника данных. Это нужно, чтобы не принять макет за настоящий API-каталог.

## Важно

Скриншот v0.5.2 с 8 кофейными позициями был красивым, но не был подтверждён как живой каталог I-Retail: отчёт показал ошибку `humanFriendlyException.doesNotExistChannel` для `channel_id=3476`, а скачанный файл каталога оказался JSON-ошибкой, а не ZIP.

Для полного подтверждения v0.5.3 нужно запустить пробник v1.3 и прислать отчёт.
