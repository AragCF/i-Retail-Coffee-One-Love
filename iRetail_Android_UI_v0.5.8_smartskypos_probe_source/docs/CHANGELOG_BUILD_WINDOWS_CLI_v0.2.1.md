# Изменения сборки Windows CLI v0.2.1

## Что исправлено

1. `BUILD_WINDOWS_CLI.bat` больше не включает `EnableDelayedExpansion`. Это важно для путей, где есть символ `!`, например `!0719 - Coffee`. В старой версии такой символ мог исчезать из пути, из-за чего появлялось сообщение `The system cannot find the path specified`.

2. Вызов `gradle --version` теперь выполняется через `call`. Это важно для Windows, потому что системная команда `gradle` обычно является `gradle.bat`. Если вызвать другой `bat`-файл без `call`, исходный скрипт завершается и до сборки APK не доходит.

3. Команды Gradle теперь запускаются с `--stacktrace`, чтобы при ошибке сборки было больше технических данных для диагностики.

## Что не менялось

- Код Android-приложения не менялся.
- Контракт UI MVP v0.2 не менялся.
- Идентификатор приложения не менялся.
- Версия APK внутри Android-проекта не менялась.
