# Отчёт реализации v0.5.1

## Сделано

- Исправлена логика выбора товаров для главного экрана.
- Убрано аварийное поведение `если кофе не найден — показать любые товары`. Именно из-за него на витрину попали парфюм и часы.
- Добавлен локальный кофейный набор как безопасный запасной вариант.
- Добавлен прокручиваемый каталог для портретного и альбомного режима.
- Убраны невидимые горячие зоны поверх карточек товаров, которые мешали бы привычной прокрутке пальцем.
- Добавлена явная подсказка прокрутки при наличии дополнительных строк.
- Обновлена классификация товаров: наличие `gcode` само по себе больше не означает, что товар кофейный.

## Текущее поведение

Если API возвращает кофейные товары — приложение показывает их.
Если API возвращает только некофейные товары — приложение сообщает об этом и показывает кофейные позиции из макета.

## Проверка

Полная сборка APK в этой среде не выполнялась: здесь нет Android SDK и Gradle wrapper. Код подготовлен для проверки через `BUILD_WINDOWS_CLI.bat` на Windows-сборочной машине.
