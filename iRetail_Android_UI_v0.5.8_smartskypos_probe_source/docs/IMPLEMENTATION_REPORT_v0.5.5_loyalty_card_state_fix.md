# Отчёт реализации v0.5.5

Причина ошибки из проверки:

- `LOYALTY_GET_CARD_QR` не был обработан в альбомном рендерере, поэтому приложение уходило в `renderLandscapeCatalogAndOrder()`.
- При балансе 0 PTS `bonusApplied` оставался 0, поэтому в заказе не было визуального признака, что карта найдена и прикреплена.

Что изменено:

- добавлено состояние `attachedToOrder` в `LocalLoyaltyGateway`;
- успешный `get-coupons-and-balance` сразу прикрепляет карту к заказу;
- добавлены строки состояния лояльности в корзине и оплате;
- добавлен отдельный экран-заглушка регистрации карты для portrait и landscape;
- изменена навигация из профиля лояльности: возврат идёт в заказ.

Ограничение:

- фактическая отправка `ibonus_discount_sum` в I-Retail order sync ещё не включена. Это следующий отдельный шаг после подтверждения формата синхронизации заказа.
