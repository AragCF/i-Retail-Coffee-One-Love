# Vendotek VT: доступ к меню, Wi-Fi и интернет через USB

Версия пакета: **0.5.33**. Источники проверены **18.09.2026**.

## 1. Исправление прежнего заключения

На нашем экземпляре уже подтверждён VTK через FTDI: Windows COM24 и JL22 `/dev/ttyUSB0`. Это канал команд, а не автоматически предоставленный терминалу интернет.

По новым сведениям проекта поставщик сообщил о готовности экземпляра к **тестовым, имитационным транзакциям** и предложил проверить интернет. Это сообщение не подтверждает реальный эквайринг, но делает прежний вывод «сначала обязательно привязать терминал к банку» преждевременным. Основание — переданная владельцем проекта переписка от 17.09.2026; сама личная переписка в открытый репозиторий не переносится.

В Wiki `IN_SERVICE` означает нахождение в сервисном меню. Для отсутствия банковской конфигурации отдельно описан `NO_BANK_CONFIG`. Поэтому наша строка

```text
STATE=BUSY,NOT_READY;READY,DESCRIPTION=IN_SERVICE
```

не доказывает отсутствие банковского профиля. Она также не доказывает, что единственная проблема — интернет. Нужно узнать проект/версию ПО, настроить канал связи и прочитать состояние после выхода из меню.

**Пропущенный шаг:** в VTKPOS-V2 точка Wi-Fi активируется картой/NFC в специальный момент загрузки. Прежний поиск после одного лишь включения питания не включал этого действия и не проверял штатную активацию меню.

- [Алгоритм загрузки V2](https://wiki.vendotek.ru/pics/trs2.png) и [индикация](https://wiki.vendotek.ru/ru/terminals/vt/leds): при входе в Wi-Fi-меню горят синий и красный светодиоды. Эти указания относятся к VTKPOS-V2, а не автоматически ко всем прошивкам VT.
- [Описание модели VT](https://termt.ru/vendotek-vt): USB — virtual COM-port; интернет — Wi-Fi либо VTK с предоставлением интернета управляющим устройством.
- [Общая проверка интернета](https://termt.ru/faq-vendotek/kak-proverit-dostup-v-internet): упоминает Ethernet-over-USB с пробросом на контроллере, но содержит экран и кнопку B1 и не подтверждает соответствующий режим у нашего конкретного VT.

## 3. Различие каналов

**VTK через COM:** Windows → USB → FTDI → последовательный порт → Vendotek. Он уже испытан с IDL/STATUS. FTDI `0403:6001` не является подтверждённым USB-сетевым интерфейсом терминала.

**Собственный Wi-Fi:** Vendotek → роутер → интернет. USB/COM при этом может оставаться каналом управления. Для получения интернета по Wi-Fi не требуется переводить транспорт VTK с RS-232 на TCP/IP.

**Сервисная точка Wi-Fi:** временное подключение телефона/ПК к меню терминала. Это ещё не подключение самого терминала к внешнему роутеру: внешняя сеть задаётся внутри меню.

**Интернет через VTK:** Vendotek → CON/DAT/DSC → программа-посредник на Windows/JL22 → интернет. Требуются настройка терминала и реализация посредника. Наши прежние IDL/STATUS и TMS-пробники этого посредника не содержали. USB-кабель сам его не заменяет.

**Ethernet-over-USB:** в переписке это высказано как требующее проверки предположение. В рисунках общего меню есть Ethernet/Modem, но модельная таблица VT перечисляет Wi-Fi, а таблица VTK дополнительно — интернет через VTK. Пункт общего интерфейса не доказывает поддержку соответствующей USB-функции конкретной моделью. Пока не установлены USB-сетевой интерфейс данного VT, его драйвер, способ переключения и адреса. Заменять работающий FTDI-драйвер на RNDIS или включать общий доступ на случайном адаптере оснований нет.

## 4. Практическая процедура для VTKPOS-V2

1. Завершить COM-тесты и закрыть программы, посылающие команды. Оставить штатное питание и USB-подключение. Карта нужна только для входа в меню, не для продажи.
2. Перезапустить питание только Vendotek. В начале — короткий сигнал и жёлтый светодиод.
3. **Когда четыре светодиода начнут мигать по очереди, приложить любую банковскую карту или устройство с NFC**, как указано изготовителем. После регистрации действия убрать карту. Наши новые сценарии не отправляют VRP.
4. Найти точку формата `Vendotek_<серийный номер>`. Маркировка нашего экземпляра `220000047601`, но фактическое имя нужно прочитать, а не считать заранее установленным.
5. Подключиться со смартфона, как показано в руководстве. Можно проверить и Wi-Fi Windows, но переключение может временно лишить компьютер его обычной сети; обновить Git следует заранее.
6. Открыть уведомление входа в сеть: должна появиться **Vendotek web config**. Ввести пароль меню и нажать **Login**. В изученных страницах значение пароля и гарантированный IP меню не указаны. При необходимости запросить у поставщика пароль именно этого тестового экземпляра; это не пароль внешней Wi-Fi-сети.
7. В **Terminal Info** записать проект и версию ПО. Это отличит VTKPOS-V1 от VTKPOS-V2.
8. **Settings → Link Settings → Connection type → Wi-Fi**. Ввести SSID/пароль внешней сети с интернетом; в обычной сети с автоматическими адресами выбрать DHCP. Применить требования производителя: 2,4 ГГц и WPA2-PSK.
9. Сохранить и выполнить **Reboot** из основного меню. При следующей загрузке не активировать сервисный режим картой: нужен обычный рабочий запуск.
10. Проверить STATUS по существующему COM-каналу. IP-адрес, доступ к TMS и готовность к продаже — разные контрольные точки; успешный IDL не удостоверяет их все.

Сетевые настройки вводит человек в штатном меню. Сценарии не меняют адреса, драйверы, общий доступ, прошивку или банковский профиль.

## 5. Если точки нет: проверить проект, а не гадать о банке

Сначала проверить момент прикладывания NFC при загрузке. Отсутствие точки или характерной последовательности не доказывает поломку Wi-Fi.

Для **VTKPOS-V1** изготовитель прямо исключает Wi-Fi-меню и указывает **утилиту headless**. Какой проект фактически установлен у нас, пока не определено. Наличие ответа STATUS этого не устанавливает.

Предметный запрос поставщику:

> Для тестового VT с маркировкой 220000047601 уточните проект и версию ПО: VTKPOS-V1 или VTKPOS-V2. VTK через FTDI A507YBKB работает. Нужны способ настройки интернета, пароль Wi-Fi-меню и, если это V1, утилита headless с инструкцией Windows. Если у этой ревизии предусмотрен именно Ethernet-over-USB, укажите процедуру включения, ожидаемые USB VID/PID, драйвер и сетевые параметры. Тестовый банковский профиль менять не требуется.

## 6. Новый пакет Windows

Всё размещается в существующей папке проекта, не на рабочем столе.

- `VENDOTEK_11_NETWORK_ACCESS_AUDIT.bat`: три наблюдения Wi-Fi, PnP FTDI и USB-сетевые кандидаты; COM не открывается. Сохраняются только имена точек Vendotek, без имён прочих сетей и без паролей. Сетевой адаптер-кандидат может принадлежать другому устройству; отсутствие сети не трактуется как отсутствие функции Wi-Fi.
- `VENDOTEK_12_STATUS_AFTER_WIFI.bat`: после ручной настройки и перезагрузки выбирает актуальный COM только по живому FTDI с серийным номером `A507YBKB` и запускает существующий IDL/STATUS. Bluetooth/COM7 и иной серийный номер отвергаются до открытия. COM24 не зашит навечно.
- `GIT_123_PUBLISH_VENDOTEK_NETWORK_RESULT.bat`: публикует последний ограниченный ZIP и SHA256 в ветку 0.5.33, проверяет ветку и отсутствие посторонних подготовленных к коммиту изменений; без force push.

Отчёты: `vendotek_network_logs\VENDOTEK_NETWORK_*.zip`. В Git попадает только ограниченный отчёт нового пакета, не переписка, не полный экспорт системы и не сырые платёжные кадры. Старый COM-клиент может оставить локальные файлы в `vendotek_com_logs`; новый издатель их не отправляет.

После попытки активации меню:

```bat
call VENDOTEK_11_NETWORK_ACCESS_AUDIT.bat
call GIT_123_PUBLISH_VENDOTEK_NETWORK_RESULT.bat
```

После настройки внешней сети, сохранения и перезагрузки:

```bat
call VENDOTEK_12_STATUS_AFTER_WIFI.bat
call GIT_123_PUBLISH_VENDOTEK_NETWORK_RESULT.bat
```

Полезны снимки Terminal Info и Link Settings **без пароля**. Пакет не выполняет оплату, TMS A, сверку, возврат или обновление ПО. Один STATUS не является приёмкой платёжного сценария.
