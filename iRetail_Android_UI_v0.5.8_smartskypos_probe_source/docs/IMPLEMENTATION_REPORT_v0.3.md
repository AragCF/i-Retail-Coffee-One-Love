# Implementation Report — i-Retail Android UI MVP v0.3

Статус: исправительный выпуск после первой проверки экранного MVP.

## Главная цель версии

Версия v0.3 исправляет ошибки экранной логики, найденные при ручной проверке v0.2.2, и аккуратно приобщает новую техническую информацию из архива `net.payinpayout.tso-master.tar.gz` и дополнительных документов по Android-приложению, фискализации и смесителю.

Важно: это всё ещё безопасный UI MVP. Реальная оплата, реальная фискализация, реальная лояльность, реальная выдача напитка и реальные команды оборудования не включены.

## Что исправлено по замечаниям

1. **Добавление товара / “У меня свой стакан”**
   - Переключатель теперь меняет состояние.
   - Состояние сохраняется в позиции корзины.
   - На экране добавления поверх макета выводится явное состояние: `○` или `✓`.

2. **Добавление сиропа**
   - Кнопки сиропов теперь меняют состояние позиции.
   - После добавления видно сообщение `Сироп добавлен`.
   - Есть экранная возможность удалить сироп до добавления товара в корзину.
   - Признак сиропа сохраняется в позиции корзины.

3. **Добавление купона**
   - Экранная цифровая клавиатура теперь работает.
   - Ввод отображается в поле купона.
   - Есть удаление последней цифры.
   - Кнопка подтверждения применяет купон в мок-режиме.
   - Окно купона теперь можно закрыть через крестик.

4. **Главное меню / выбор напитка**
   - Теперь при выборе карточки выбирается соответствующий товар из мок-каталога.
   - На экране добавления товара поверх исходного PNG выводятся реальные название, объём и цена выбранного товара.
   - Это исправляет прежнее поведение, когда визуально всегда выбирался капучино.

5. **Главное меню / удаление товара и неактуальный заказ**
   - Очистка заказа теперь полностью сбрасывает локальную корзину, купон и временные модификаторы.
   - После очистки приложение возвращается в пустой каталог, а не показывает старые позиции.
   - На экранах заказа поверх статичного PNG выводится актуальное содержимое локальной корзины.

6. **Ваш заказ / возврат назад**
   - Добавлена экранная навигация назад через область в верхней левой части экрана.
   - Стандартные кнопки Android не требуются.
   - Аппаратная кнопка Back, если она всё же доступна, также ведёт по безопасной внутренней истории экранов.

7. **Система лояльности**
   - Цифровая клавиатура теперь работает.
   - Ввод отображается в поле.
   - Кнопка удаления последней цифры работает.
   - Кнопка подтверждения переводит на профиль лояльности в мок-режиме.
   - Экранная кнопка назад возвращает в каталог/заказ.

8. **Выдача товара / “Мы рекомендуем”**
   - Добавлены зоны выбора для нескольких рекомендованных предложений.
   - После выбора показывается отдельное всплывающее окно с названием предложения.
   - Всплывающее окно можно закрыть через крестик или кнопку `Закрыть`.
   - Реальная покупка рекомендованного предложения не подключалась, чтобы не имитировать боевую продажу без контракта.

## Что добавлено в кодовую модель

- В `CartLine` добавлены признаки:
  - `ownCup` — свой стакан;
  - `syrupAdded` — добавлен сироп.
- Добавлен динамический слой поверх PNG-макетов для отображения актуальных данных:
  - выбранный товар;
  - актуальная корзина;
  - сумма заказа;
  - введённый купон;
  - введённый код лояльности;
  - всплывающее окно рекомендованного предложения.
- Навигация остаётся одноэкранной, без AndroidX, чтобы сохранить совместимость с Android 6.

## Что учтено из `net.payinpayout.tso-master.tar.gz`

Из найденного проекта полезны следующие архитектурные идеи и требования, но не готовый код для прямого переноса в Android-приложение:

- экранная клавиатура должна быть управляемой самим приложением;
- сценарий корзины может быть нижним, компактным или полноэкранным;
- товар может открываться как карточка или сразу добавляться в корзину;
- для напитков важны отдельные признаки: свой стакан, стаканчики, кофемашина, чайная станция, лимонадная/смесительная станция;
- лояльность, касса, оплата, выдача и оборудование должны жить за отдельными шлюзами/адаптерами;
- фискализация и выдача не должны смешиваться с визуальной логикой экрана.

В v0.3 эти идеи отражены в разделении на мок-шлюзы и экранный слой. Прямой перенос Java-кода из TSO-проекта не сделан: он ориентирован на другую среду исполнения, Swing/десктопные компоненты и внешнюю конфигурационную систему.

## Что учтено из дополнительных документов

### Техническое задание на Android-приложение

Подтверждены будущие границы боевой версии:

- каталог;
- оформление заказа;
- лояльность;
- POS-терминал;
- кофемашина через Raspberry Hub;
- лимонадная и чайная станции;
- онлайн-касса;
- QR/электронный чек;
- без реализации MDB-блока на текущем этапе.

### API web-фискальник

Зафиксировано, что фискализация должна быть отдельным слоем, принимающим состав покупки, платежи, скидки, НДС/ставки и режим печати/отправки. В v0.3 фискализация не вызывается.

### Команды смесителя

Зафиксированы будущие требования к отдельному адаптеру смесителя:

- подключение по Socket/IP;
- порт 7;
- команды разной длины: 2, 4, 6, 8, 10, 12 байт;
- в многобайтных величинах первым передаётся младший байт;
- для команд длиннее 2 байт нужен контрольный байт по сумме `& 0xFF`;
- неизвестная команда возвращает `0x10`.

В v0.3 эти команды не отправляются.

## Честные ограничения v0.3

1. Макеты всё ещё используются как PNG-подложки. Динамический слой закрывает отдельные статичные места, но не является полноценной ручной вёрсткой каждого элемента.
2. Точные границы касаний нужно проверить на реальном экране Jetinno JL22 и при необходимости поправить координаты.
3. Реальный каталог, реальные изображения товаров, реальные цены и доступность должны прийти из backend API отдельным контрактом.
4. Реальная лояльность, оплата, касса и оборудование пока заменены безопасными мок-шлюзами.
5. Рекомендации после оплаты пока не создают реальный товар/абонемент. Они только проверяют выбор и закрытие всплывающего окна.

## Минимальный набор ручной проверки

1. Выбрать каждый напиток в главном меню и убедиться, что на экране добавления видно правильное название.
2. На экране добавления включить/выключить `У меня свой стакан`.
3. Добавить сироп, увидеть состояние, удалить сироп.
4. Добавить товар в корзину и проверить актуальную корзину.
5. Очистить заказ и убедиться, что старые позиции исчезли.
6. Открыть `Ваш заказ`, вернуться назад экранной кнопкой.
7. Открыть купон, ввести цифры, стереть цифру, закрыть окно.
8. Открыть лояльность, ввести цифры, стереть цифру, вернуться назад.
9. Дойти до оплаты, завершить мок-оплату, выбрать каждое рекомендованное предложение и закрыть всплывающее окно.
