# v0.5.5 — исправление состояния карты лояльности

Исправлено:

- карта лояльности теперь считается привязанной к заказу сразу после успешного ответа I-Retail;
- при нулевом балансе отображается не «скидка не применена», а честное состояние: карта есть, скидка 0 ₽;
- кнопка профиля карты при нулевом балансе возвращает в заказ;
- экран «Получить карту» в landscape больше не падает в каталог из-за отсутствия отдельного рендера;
- возврат из профиля лояльности ведёт в заказ, а не в каталог.
