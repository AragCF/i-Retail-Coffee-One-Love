# i-Retail Android UI v0.5.1 — фильтр кофейного меню и прокрутка каталога

## Что исправлено

1. Главный экран больше не показывает товары, не относящиеся к кофе, если выбранный канал I-Retail возвращает парфюм, часы, сумки или другие товары.
2. Если в удалённом каталоге нет кофейных позиций, приложение явно сообщает об этом и показывает кофейный набор из локального макета, а не случайные товары из API.
3. Каталог на главном экране теперь прокручивается как обычный список: пальцем вверх/вниз.
4. Добавлена видимая подсказка прокрутки и постоянная полоса прокрутки, когда позиций больше, чем помещается на экран.
5. Карточки товаров теперь сами обрабатывают касание; отдельные невидимые области поверх карточек убраны, чтобы они не ломали прокрутку.

## Подтверждённый факт по текущему API

Канал `3115` реально отдаёт не кофейное меню. В последнем проверочном отчёте ZIP-каталог содержал 104 доступных товара: парфюмерия SHAIK, часы, сумки и люксовые категории. Поэтому проблема на скриншоте была не в отрисовке, а в том, что выбранный канал/каталог не соответствует кофейному автомату.

## Что нужно дальше

Для настоящего кофейного меню нужен канал I-Retail, в котором заведены кофейные товары: капучино, американо, латте, эспрессо, какао и т.п. Пока такого канала нет или он не указан, приложение будет показывать безопасный кофейный набор из макета и не будет подмешивать парфюм/часы в кофейную витрину.
