## Исправления

- Работает переключатель “У меня свой стакан”.
- Работает добавление/удаление сиропа.
- Работает клавиатура купона и закрытие окна купона.
- В главном меню выбирается правильный напиток.
- Корзина больше не показывает старые позиции после очистки.
- Добавлена экранная навигация назад в заказе и лояльности.
- Работает клавиатура лояльности.
- В рекомендациях после оплаты можно выбрать несколько предложений и закрыть всплывающее окно.
