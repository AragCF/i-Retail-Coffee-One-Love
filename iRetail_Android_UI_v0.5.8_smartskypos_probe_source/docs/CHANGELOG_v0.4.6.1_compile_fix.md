# CHANGELOG v0.4.6.1 — исправление сборки Kotlin

Дата: 2026-06-02

## Что исправлено

- Исправлена ошибка `Unresolved reference 'LayoutParams'` в `MainActivity.kt`.
- В `ScrollView.addView(...)` теперь используется `FrameLayout.LayoutParams`, совместимый с Android/Kotlin.
- Обновлена версия в `BUILD_WINDOWS_CLI.bat`, чтобы журнал сборки больше не показывал старую подпись v0.4.5.

## Что не менялось

- Визуальная логика v0.4.6 не переписывалась.
- Альбомная ориентация, прокручиваемая корзина и иконка удаления сохранены.
- Боевые интеграции оплаты/железа не включались.

## Проверка в этой среде

Полную Gradle/Android SDK сборку здесь выполнить невозможно. Выполнена статическая проверка исходников: устаревшая ссылка `ScrollView.LayoutParams` удалена из Kotlin-кода.
