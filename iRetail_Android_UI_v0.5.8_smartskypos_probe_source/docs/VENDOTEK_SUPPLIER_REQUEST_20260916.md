# Vendotek VT — запрос поставщику / эквайеру

Здравствуйте.

Мы интегрируем встраиваемый терминал Vendotek VT с приложением i-Retail на кофе-машине. Транспорт VTK уже проверен на реальном оборудовании и работает как через Android/Linux, так и напрямую из Windows.

## Идентификация экземпляра

Маркировка с корпуса/платы:

```text
220000047601
```

USB интерфейс:

```text
FTDI FT232R USB UART
VID:PID 0403:6001
FTDI serial A507YBKB
Windows VCP: COM24
Android/Linux: /dev/ttyUSB0
```

Последовательный режим:

```text
115200 8N1
no flow control
```

## Что работает

VTK работает двусторонне:

- IDL — корректный ответ;
- CRC16-CCITT — корректный;
- BER-TLV — корректный;
- STATUS — корректный ответ;
- интерфейс работает как через JL22 Android 6, так и напрямую из Windows через COM24.

Текущий STATUS после холодной загрузки стабильно возвращается как:

```text
STATE=BUSY,NOT_READY;READY,DESCRIPTION=IN_SERVICE
```

Состояние не меняется как минимум в восьми последовательных запросах с интервалом около 10 секунд.

## Дополнительные проверки

На запросы System Information:

```text
POS_PARAMS
BANK_PARAMS
NET_PARAMS
```

терминал возвращает обычный IDL, но без соответствующих данных.

Один явно разрешённый запрос:

```text
POS Management data = A
```

был принят терминалом, после чего он вернул обычный IDL. В течение примерно 45 секунд не наблюдались:

```text
CON
DAT
DSC
Stage 921
Stage 922
```

STATUS после запроса не изменился.

## Просим проверить

Пожалуйста, проверьте для данного экземпляра:

1. зарегистрирован ли терминал в TMS;
2. привязан ли он к тестовому эквайринговому/платёжному контуру;
3. назначены ли тестовые TID/MID;
4. загружен и активирован ли банковский/эквайринговый профиль;
5. загружены ли необходимые криптографические ключи/сертификаты;
6. настроены ли адреса и параметры процессинга;
7. настроен ли сетевой/TMS профиль;
8. разрешена ли операция продажи;
9. какой STATUS должен возвращаться у полностью готового к оплате VT;
10. должна ли команда `POS Management data = A` инициировать TMS-сессию на данной версии прошивки;
11. должны ли поддерживаться `POS_PARAMS`, `BANK_PARAMS`, `NET_PARAMS`;
12. как штатно активировать сервисную Wi-Fi точку/меню техника на безэкранном VT.

Нам нужен именно **тестовый контур**, чтобы выполнить первую безопасную продажу минимальной суммы и проверить цепочку `VRP -> результат -> FIN` без риска для боевого эквайринга.

Финансовые операции до подтверждения готовности терминала мы не выполняем.
