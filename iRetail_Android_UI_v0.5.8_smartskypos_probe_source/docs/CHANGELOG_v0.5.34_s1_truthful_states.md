## 🟡 Изменено

- Достоверное одобрение Kozen переводит заказ только в состояние `PAID`. Фискализация остаётся отдельным последующим действием.
- Наличные и онлайн-оплата в обычном пользовательском пути теперь сообщают о недоступности вместо локального «успеха».
- Подтверждение стакана, выдача и разогрев больше не возвращают фиктивный успех от локального исполнителя.
- Отправка электронного чека не переходит на экран успешной отправки без реального сервиса.

## 🔴 Удалено из обычного покупательского сценария

- Завершение наличной/онлайн-оплаты по таймеру.
- Автоматический переход QR → «продолжить оплату» → локальный успех.
- Автоматическое завершение выдачи по таймеру.
- Локальная ссылка `local://receipt/...` как суррогат фискального чека.
- Автоматическое присвоение `FISCALIZED` после локального завершения оплаты.
- Фиктивные 100% успеха выдачи и разогрева.

## Сохранено без изменения

- Запрет автоматического повтора финансового запроса.
- Восстановление/блокировка неопределённого платежа Kozen.

- Каталог, лояльность и существующие пути API — их доработка относится к следующим этапам.
