# i-Retail Android UI v0.4.5 — язык, лояльность и читаемость

## Что исправлено

1. Верхний флаг больше не открывает систему лояльности. Теперь он открывает отдельное окно выбора языка.
2. Система лояльности перенесена в пользовательский сценарий «Оплатить со скидкой»: при наличии заказа нижняя кнопка ведёт на ввод карты/кода лояльности.
3. Увеличен масштаб живых текстовых элементов интерфейса, чтобы динамические подписи не выглядели мельче исходных макетов Figma на планшете/эмуляторе.
4. Дополнительно увеличены основные подписи в окне добавления товара: название напитка, объём, цена, «свой стакан», сиропы, кнопки выбора/удаления сиропа.
5. Полноэкранный заказ теперь закрывает статичные остатки фонового PNG, чтобы внизу не появлялся второй, неактуальный блок оплаты.
6. Проверена логика горячих областей: выбор языка не перекрывает крестики закрытия в модальных окнах товара, купона и еды.

## Что осталось в рамках будущей интеграции

Выбор языка сейчас реализован как полноценный интерфейсный сценарий, но без полной словарной локализации всех экранов. Для боевого режима нужен словарь RU/EN/KZ/других языков и контракт на переключение текстов, получаемых из серверного контента.
