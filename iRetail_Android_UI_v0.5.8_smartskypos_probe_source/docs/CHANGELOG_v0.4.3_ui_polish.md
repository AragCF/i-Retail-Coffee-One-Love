# iRetail Android UI v0.4.3 — исправление очевидных ошибок интерфейса

## Что исправлено

1. Главное меню:
   - убрано наложение динамических названий напитков поверх Figma-макета;
   - порядок выбора напитков приведён к визуальному порядку карточек: Капучино, Американо, Какао, Флэт Уайт, Американо XL, Капучино XL, Эспрессо, Латте;
   - динамически обновляется цена из XML-каталога без дублирования названия и объёма.

2. Добавление товара:
   - карточка выбранного напитка теперь перерисовывается поверх статичного PNG: правильное название, объём, цена и изображение;
   - строка «У меня свой стакан» больше не дублируется и не накладывается на исходный текст;
   - блок сиропов полностью перерисован: добавление видно сразу, выбранный сироп отмечается галочкой, есть понятная кнопка удаления;
   - убрано наложение «Сироп» и «Удалить».

3. Корзина и заказ:
   - нижний блок заказа на главном экране теперь полностью живой и закрывает устаревшие данные из PNG;
   - сумма считается по реальным позициям корзины;
   - кнопка оплаты больше не содержит наложенный текст;
   - в полном экране заказа появились живые строки заказа, управление количеством, очистка и возврат назад внутри интерфейса.

4. Повторная проверка:
   - проверена Kotlin-синтаксическая сборка с локальными Android-заглушками;
   - пересмотрены основные зоны, где статичный Figma-экран конфликтовал с динамическим слоем.

## Важное ограничение

Это всё ещё экранный Android-прототип на Kotlin без подключённого боевого POS/кассы/кофемашины. Внешние интеграции сохранены на уровне локальных безопасных адаптеров, чтобы интерфейс можно было показать без риска списания денег или отправки команд на оборудование.
